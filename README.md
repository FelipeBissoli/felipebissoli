👨‍💻 Sobre Mim
Sou um entusiasta de tecnologia e Tecnólogo em Ciência de Dados (6º semestre) apaixonado por transformar grandes volumes de dados em decisões inteligentes. Meu dia a dia acontece no Zorin OS (Linux), onde exploro o poder do Open Source para construir automações e análises de alto impacto.

Já a área de produção audiovisual na Valem Digital, gerenciando a entrega estratégica para 6 empresas, enquanto aplicava inteligência de dados para otimizar processos e alcançar metas.


Linguagens: Python (Pandas, NumPy, TensorFlow, Telethon).

Dados: MySQL, PostgreSQL (Otimização e ETL), Web Scraping.

Visualização: Power BI (Dashboards Estratégicos), Dash/Streamlit.

Ambiente atual: Linux (Zorin OS) | Ryzen 7 7735HS | 8GB RAM.
